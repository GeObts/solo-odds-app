# Solo Mining Odds — Mobile App

A native mobile (Android + iOS) port of the Solo Mining Odds Calculator from
[basedmining.xyz/calculator](https://basedmining.xyz/calculator).

Built as a **Vite + React + TypeScript** web app wrapped with **Capacitor**, so it
can be imported into **Ionic / Capacitor** tooling (Ionic dashboard → *Import app*)
or built directly with the Capacitor CLI / Xcode / Android Studio.

The calculator math, formatters, and layout are ported verbatim from the website.
See [`SPEC.md`](./SPEC.md) for the full feature spec and the canonical source of truth.

---

## Stack

| Layer        | Choice                                            |
| ------------ | ------------------------------------------------- |
| UI           | React 18 + TypeScript                             |
| Bundler      | Vite 5                                            |
| Native shell | Capacitor 6 (`@capacitor/android`, `/ios`)        |
| Plugins      | `@capacitor/share`, `@capacitor/clipboard`        |
| Live data    | `api.basedmining.xyz` + `mempool.space` (price)   |

## Develop in the browser

```bash
npm install
npm run dev          # http://localhost:5173  (Vite proxies /api → api.basedmining.xyz)
```

## Build the web bundle

```bash
npm run build        # → dist/   (this is what Capacitor wraps)
```

## Turn it into a native app

### Option A — Ionic dashboard (what you'll use)
1. Push this repo to git (it already has a `capacitor.config.ts`, so it imports as a Capacitor project).
2. In the Ionic dashboard choose **Import app → Connect your git repository**.
3. It detects Capacitor and scaffolds the native builds.

### Option B — Capacitor CLI locally
```bash
npm install
npm run build
npx cap add android      # and / or:  npx cap add ios
npm run sync             # copies dist/ into the native projects
npx cap open android     # opens Android Studio  (npx cap open ios → Xcode, macOS only)
```

> `android/` and `ios/` are gitignored — they're generated by `cap add` and by the
> wrapper tool, so the JS repo stays clean.

## App identity

- **App ID:** `xyz.basedmining.soloodds`
- **App name:** `Solo Mining Odds`

Change these in `capacitor.config.ts` before the first native build if needed.

## Notes / differences from the web calculator

- **Share:** the website's X / Farcaster / WhatsApp button row is replaced by the
  native share sheet (`@capacitor/share`), plus *Post to X* and *Copy Link*.
- **CORS:** `CapacitorHttp` is enabled so on-device `fetch` to `api.basedmining.xyz`
  works natively. In the browser dev server, Vite proxies `/api` instead.
- **Image download:** the web "Download odds card" (canvas → PNG) is **not yet ported** —
  it needs `@capacitor/filesystem` + gallery permissions. Tracked as a follow-up.
- **No URL state seeding:** the web app reads `?hash=&unit=` from the URL; the app
  starts at the default (1 EH/s). Deep-link seeding is a possible future addition.
